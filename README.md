# Vaccine Market Intelligence

Internal resource for Sanofi's Competitive Intelligence work, part of Vaccine Performance and Innovation team  (Vaccines, Performance and Innovation team). Not an official Sanofi website.

Public, official sources only. No confidential Sanofi data.

## Pages
- Company profiles: Sanofi, Moderna, GSK, MSD, Pfizer, AstraZeneca
- Learn: Like I'm 5, Vaccine basics, Marketplace, Price types and rules, Glossary
- Today: Competitor news, Sanofi update (7-day news log)

## How to edit
All content lives in `index.html`, in the data blocks marked:
- `EDIT HERE` (company pages)
- `ACRONYMS` (acronym glossary)
- `VACCINE BASICS PAGE`
- `LEARN PAGES` (Like I'm 5, Marketplace, Price types)
- `GLOSSARY` (extra terms)
- `TODAY PAGES` (news log)

Changes pushed to `main` go live on GitHub Pages in about 1 minute.
